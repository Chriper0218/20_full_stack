Inventario - Proyecto DESARROLLO WEB FULL STACK

Presentación:

Este repositorio contiene la aplicación de inventario desarrollada para la materia DESARROLLO WEB FULL STACK de la Universidad de la Costa (Barranquilla, Colombia). Por parte de Christian Perez Vega.

Descripcion:

Esta aplicación facilita la gestión de inventarios, mantenimiento y reportes para una organización pequeña o mediana. Está construida con Next.js y una API interna para autenticación, usuarios, mantenimiento y reportes.

Qué puedes hacer con esta app:
-Gestionar usuarios: Crear, listar y administrar usuarios.
-Registrar ítems de inventario: Añadir, editar y eliminar elementos del inventario.
-Registrar y gestionar mantenimientos: Programar y dar seguimiento a mantenimientos por ítem.
-Generar reportes: Consultar reportes de inventario y estadísticas del tablero.

Registro de administradores:

Para registrarte como administrador al crear un nuevo usuario, utiliza la clave de registro: `CUC-2026`. Sin esta clave, el registro creará un usuario con permisos estándar.
